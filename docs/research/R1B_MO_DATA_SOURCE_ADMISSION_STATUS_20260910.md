## Source assessment

### 1. CFFEX official historical data service — preferred

CFFEX states that its historical data products cover historical market data generated by listed products/contracts, including snapshot data, and provides four product families: Level-2, Level-1, one-minute and five-minute historical databases.

For this R1_B identity, the correct acquisition target is **official Level-1 or Level-2 historical data with best bid/ask snapshots**, not the one-minute/five-minute OHLC database.

Official references:

- https://www.cffex.com.cn/lssjfw/
- https://www.cffex.com.cn/zlxz/
- https://www.cffex.com.cn/zz1000gzqq/

Status: `PREFERRED_SOURCE_NOT_YET_ACQUIRED`

### 2. AKShare / Sina MO interfaces — not admitted for historical primary execution

AKShare documents an MO board/spot interface exposing bid/ask-like fields for current/real-time snapshots, and a separate historical daily interface. That does not establish a provenance-stable historical intraday best-bid/best-ask tape for 2022-2025.

Status: `NOT_ADMISSIBLE_FOR_PRIMARY_HISTORICAL_EXECUTION_FROM_DOCUMENTED_INTERFACE`

### 3. Tushare `opt_mins` — not admitted for primary execution

Tushare documents historical option minute bars with fields such as open/close/high/low/volume/amount/open interest. The documented output does not include historical best bid, best ask, or quote sizes.

Minute OHLC can be useful for non-economic feasibility or inventory checks but cannot support the primary R1_B execution mapping because it suppresses executable spread.

Status: `NOT_ADMISSIBLE_FOR_PRIMARY_EXECUTION_FROM_DOCUMENTED_FIELDS`
