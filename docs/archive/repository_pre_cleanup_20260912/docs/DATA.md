## 字段与质量

- 价格是指数点；amount为区间成交额CNY，非累计，volume为null，不能冒充股数或换手率。
- 原时间字符串虽带Z，数字部分按父合同为上海墙钟；读取器以此前19字符localize Asia/Shanghai，不能当UTC后再加8小时。
- 3s原主键包含`symbol/observation_datetime/row_index`；存在同秒不同序列行，不能简单删掉。产品名3s不意味着每个3秒网格都有数据，历史观测密度变化不能直接当作交易事件到达强度。
- 保留集合竞价和少量盘后观察，研究者须明确会话筛选；不得把它们自动当成可交易连续时段。
- 1m/5m保留`causal_flat_fill/source_minute_count/high_frequency_analysis_eligible`等原标记，缺口/短日不可静默填补。高频研究须显式选择质量口径并报告敏感性。
- 指数观测不提供订单簿、真实买卖方向、撤单、新闻或期权IV；因此不能直接支持完整微观结构模型。
- 历史`available_at`是获取可用语义，不是逐笔实时接收回执。每种预测特征仍须自行证明只用决策前已闭合观测。
