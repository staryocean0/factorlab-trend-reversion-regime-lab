## R1 / R2 / R3 Stage-1

### R1

Decision: `R1_STAGE1_v1_evidence_insufficient_event_measurement_too_sparse`.

Resolved events were only 9 BUILD / 5 in 2019 / 3 in 2020. The failure was **event-measurement supply**, not falsification of the economic idea. Requiring the adverse lower-scale move itself to become a complete published L3 two-wave parent was too restrictive and too delayed.

Retained contribution: use the complete M0 two-wave structure as the **parent state**, but measure the lower-scale counter-move with a lighter causal event definition when testing the R1 economic mechanism.

### R2

Decision: `R2_STAGE1_v1_evidence_insufficient_sparse_and_chronologically_unstable`.

Resolved events were 37 BUILD / 11 in 2019 / 10 in 2020, below the frozen supply gate. The source adjudication likewise concluded that an already-complete L3 parent is too heavy a carrier for a boundary excursion.

Retained contribution: keep the frozen parent range/envelope, but a future R2 measurement identity may use the **first causal close outside the frozen parent envelope** rather than requiring another complete lower-scale structure.

### R3

Decision: `R3_STAGE1_v1_closed_predeclared_deterioration_direction_falsified`.

Supply was ample (744 BUILD / 172 in 2019 / 144 in 2020), but both preregistered deterioration coefficients had the opposite sign from the frozen hypothesis:

- translation decay coefficient: `-0.04937` (required `>0`);
- quality decay coefficient: `-0.12734` (required `>0`).

The small Brier improvements therefore cannot be post-hoc reinterpreted as support. R3 v1 stays closed.
