## 4. Schema：字段顺序、含义、单位、时间与空值

编码未单独注明处，CSV 为 `utf-8-sig`。十档日包内 CSV 为 **GBK**，表头带尾逗号。

### 4.1 十档 `行情.csv`（66 列 + 尾逗号）

`万得代码,交易所代码,自然日,时间,成交价,成交量,成交额,成交笔数,IOPV,成交标志,BS标志,当日累计成交量,当日成交额,最高价,最低价,开盘价,前收盘,申卖价1…申卖价10,申卖量1…申卖量10,申买价1…申买价10,申买量1…申买量10,加权平均叫卖价,加权平均叫买价,叫卖总量,叫买总量,不加权指数,品种总数,上涨品种数,下跌品种数,持平品种数,`

| 字段 | 实测格式 / 单位 |
|---|---|
| 万得代码 | `000001.SZ` |
| 交易所代码 | `000001`（无后缀） |
| 自然日 | `YYYYMMDD` |
| 时间 | `HHmmssSSS`，如 `091500050`、`150003000`；可见 `084057000` 盘前占位 |
| 成交价及各档价格、前收盘、最高最低开盘 | 整数 ×10000。`91600` = 9.16 |
| 成交量 / 当日累计成交量 | 股。末笔 `579500` 股 × 9.16 ≈ 同期成交额 |
| 成交额 / 当日成交额 | 元 |
| IOPV | 000001 全日为 0 |
| 空档 / 未开盘 | 价格量多为 `0`；`成交标志`/`BS标志` 可空 |

### 4.2 十档 `逐笔成交.csv`（12 列）

`万得代码,交易所代码,自然日,时间,成交编号,成交代码,委托代码,BS标志,成交价格,成交数量,叫卖序号,叫买序号,`

- `成交代码=C` 出现在撤单行（20170103 首行 `C`，成交价 0、数量 100、`BS` 空）。
- 成交行 `BS` 为 `B`/`S`；价格仍 ×10000，数量为股。
